# GoMining ROI Calculator

Una calculadora interactiva de Retorno de Inversión (ROI) para la minería de Bitcoin en la nube, diseñada para educar a los usuarios sobre los beneficios del hosting de minería y redirigirlos a la plataforma **GoMining** con un código de referido exclusivo (`tCW6U`).

## Características
- **Interfaz Web Moderna**: Diseño responsive con vidrio morphism.
- **Estimación en Tiempo Real**: Calcula BTC minado, USD ganados, beneficio neto y ROI porcentual.
- **Integración de Afiliados**: Botón de conversión directo con enlace de referido de GoMining.

## Tecnologías Utilizadas
- HTML5, CSS3 y JavaScript vanilla (sin dependencias externas).

## Despliegue
Este proyecto está configurado para desplegarse automáticamente en GitHub Pages.

## Propósito Comercial
- Generación de leads calificados para el programa de referidos de GoMining.
- Educar al mercado sobre la minería en la nube como alternativa de baja complejidad técnica.
- Generar comisiones pasivas a través del código de referido `tCW6U`.
